# To-Do List — Kanban Board

A task management app built with vanilla HTML, CSS, and JavaScript. Tasks move through three stages — To Do, In Progress, and Completed — and persist across page refreshes using localStorage.

## Features
- Add, delete, and move tasks between stages
- Data persists using localStorage (tasks survive page refresh)
- Clean, responsive column layout

## Built with
- HTML5
- CSS3 
- JavaScript
